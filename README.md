# 음성공장 통근버스 · 정적 버전

별도 서버, Node.js, 데이터베이스, 빌드 과정 없이 **GitHub Pages에 그대로 올리면 실행되는 정적 웹앱**입니다.

## 바로 배포하기

1. 이 ZIP의 내용물을 모두 압축 해제합니다.
2. GitHub의 `Commuter-bus` 저장소 루트에 **파일과 폴더를 그대로 업로드**합니다.
   - `index.html`이 저장소 최상단에 있어야 합니다.
   - ZIP 파일 자체를 올리지 말고, 압축을 푼 내용물을 올립니다.
3. GitHub에서 `Settings → Pages`로 이동합니다.
4. `Deploy from a branch` / `main` / `/(root)`를 선택하고 저장합니다.
5. 배포가 끝나면 `https://kwontaekwang.github.io/Commuter-bus/`에서 확인합니다.

기존 Node.js 버전 파일이 저장소에 남아 있어도 `index.html`이 루트에 있으면 이 정적 화면이 먼저 열립니다. 혼선을 줄이려면 기존 파일은 별도 브랜치에 보관한 뒤 새 파일로 교체하는 것이 좋습니다.

## 사용자 기능

- 노선명·정류장·시간대 통합 검색
- 지역, 운행 유형, 시간대 필터
- 노선 상세 정류장 타임라인
- 즐겨찾기(사용자의 브라우저에 저장)
- 노선 링크 공유
- 모바일/태블릿/PC 반응형
- 무료 Pretendard 웹폰트와 시스템 한글 폰트 대체 설정
- 다크 모드
- 홈 화면 설치 및 오프라인 캐시(PWA 지원 브라우저)

## 관리자

- 주소: `admin.html`
- 초기 비밀번호: `bus2026`
- 로그인 후 노선 정보와 정류장 추가·수정·삭제·순서 변경 가능
- 수정 내용은 **현재 브라우저의 localStorage에만 저장**되며, 같은 브라우저의 사용자 화면에는 즉시 반영됩니다.
- 모든 사용자에게 배포하려면 관리자 화면에서 `app-data.js 내보내기`를 누른 뒤, 저장소의 `js/app-data.js` 파일을 교체합니다.
- JSON 백업/복원도 지원합니다.

### 관리자 보안의 한계

GitHub Pages는 정적 호스팅이므로 서버에서 비밀번호를 검증할 수 없습니다. 관리자 로그인은 편집 화면을 가리는 **간편 보호**이며 강한 보안 장치가 아닙니다. 민감한 개인정보나 비밀 데이터는 저장하지 마세요. 강한 인증이 필요하면 Netlify Functions, Cloudflare Workers, 별도 API 서버 같은 서버 측 인증이 필요합니다.

## 데이터 직접 교체

관리자 화면에서 내보낸 파일을 사용하는 것이 가장 쉽습니다. 수동 편집 시에는 `js/app-data.js`의 `window.COMMUTER_BUS_DATA` 객체 구조를 유지해야 합니다. `data/routes.json`은 읽기 편한 백업본이며, 실제 사용자 화면은 로컬 파일 실행도 가능하도록 `js/app-data.js`를 사용합니다.

## 문제 해결

- **README만 보일 때**: 저장소 루트에 `index.html`이 있는지 확인합니다.
- **옛 화면이 보일 때**: 브라우저에서 강력 새로고침하거나 사이트 데이터를 삭제합니다. 서비스 워커 캐시가 갱신되는 데 한 번의 새로고침이 더 필요할 수 있습니다.
- **수정 내용이 다른 PC에 안 보일 때**: 브라우저 저장은 해당 기기에만 적용됩니다. `app-data.js`를 내보내 저장소 파일을 교체해야 합니다.
- **관리자 비밀번호를 잊었을 때**: 해당 사이트의 브라우저 저장 데이터를 삭제하면 초기 비밀번호로 돌아갑니다.
